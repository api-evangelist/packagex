# PackageX

> Vision-AI powered logistics execution. PackageX turns any camera or device into an intelligent scanning agent that automates receiving, inventory, fulfillment and dispatch, and exposes a REST API for shipments, deliveries, tracking, documents and vision inferences (shipping-label OCR, bill-of-lading, item segmentation). Authentication is API-key via the PX-API-KEY header.

## APIs
- [PackageX Shipments API (production)](https://api.packagex.io): REST base URL for the platform.
- [Sandbox API](https://sandbox--api.packagex.io): isolated test environment; identical behavior, fake payments.

## Specs
- [OpenAPI (shipments)](https://raw.githubusercontent.com/packagex-io/openapi/main/openapi/spec3.yml): first-party OpenAPI 3.0 for the Shipments surface.
